# FinWise - Expense Tracker

FinWise is a simple web-based expense tracking website that helps users
record and manage their daily expenses.

## Features

- User login and signup
- Add and track expenses
- Simple and user-friendly interface
- View expense information
- Responsive web design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Home page
- `login.html` - Login page
- `signup.html` - Signup page
- `script.js` - JavaScript functionality
- `style.css` - Website styling

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

## Purpose

This project is developed as a simple expense tracking website and
demonstrates basic web development concepts.
